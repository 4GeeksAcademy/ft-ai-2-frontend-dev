# Agent Skills

Agent skills live here and should follow the spec found [here](https://agentskills.io/specification).  Maintain an index of skills in this readme.

## Index

| Skill | Description |
|---|---|
| [CLI Project Bootstrapping](./cli-project-bootstrapping/SKILL.md) | Scaffold new projects using official CLI tools (Next.js, Vite, Python/uv, Cargo, etc.) instead of manual file creation. |
| [Design Doc Mermaid](./design-doc-mermaid/SKILL.md) | Create Mermaid diagrams (activity, deployment, sequence, architecture) from text descriptions or source code, with Python utilities for extraction and image conversion. |
