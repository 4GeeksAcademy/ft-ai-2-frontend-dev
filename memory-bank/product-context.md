# Product Context

Testing demo is a series of 2 minimal examples demonstrating concepts around automated testing, including both passing and failing tests.

## Directory setup

- `memory-bank/`: The agent memory bank
- `fastapi/`: This will demonstrate testing a minimal FastAPI application with tests on business logic.
- `nextjs/`: This will demonstrate testing a nextjs application using vitest.

## Tech Stack

- `uv` for python package management
- `fastapi[standard]` for the fastapi demonstration
- `tinydb` with `MemoryStorage` for fastapi data storage
- `unittest` for python testing
- `nextjs@latest` for the nextjs application using
- `vitest` for nextjs business logic testing
- `playwright` for frontend testing.
