# MVP Specs

This directory contains the specifications for the **Auth Demo**. Each file
covers a specific aspect of the application. These specs define the scope and
design decisions for the first working version.

## File Index

| File | Covers | Status |
|------|--------|--------|
| [project-architecture.md](project-architecture.md) | Monorepo layout, tech stack, directory structure, data flow, environment variables | ✅ Ready |
| [backend.md](backend.md) | API routes, request/response schemas, models, token behavior, conventions | ✅ Ready |
| [security.md](security.md) | Authentication flow, JWT structure, password policy, threat mitigations, known gaps | ✅ Ready |
